# Phase 8 — Performance & 3D Hardening

## Mission

Measure and optimize the actual product.

## Measure

- build size
- JavaScript bundles
- initial load
- image sizes
- 3D asset sizes
- desktop FPS
- laptop FPS
- mobile behavior
- GPU/CPU pressure where measurable
- memory/resource disposal
- layout stability

## Optimize

Use evidence-based changes such as:
- LOD
- instancing
- compressed textures
- asset preloading only where justified
- lazy loading
- capped pixel ratio
- reduced shadows
- reduced post-processing
- scene pausing when not needed

Do not degrade the visual concept without documenting the tradeoff.

Create `docs/reports/PHASE_8_REPORT.md` with before/after measurements.
