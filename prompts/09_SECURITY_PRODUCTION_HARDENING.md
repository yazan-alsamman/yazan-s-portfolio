# Phase 9 — Security & Production Hardening

## Mission

Perform a production security audit.

## Audit

- authentication
- sessions
- authorization
- admin exposure
- CSRF
- XSS
- content sanitization
- uploads
- MIME validation
- file size limits
- secrets
- environment variables
- headers
- CSP compatibility
- dependency vulnerabilities
- error leakage
- backups
- logging

## Rule

Do not claim security is complete merely because a scanner is clean.

Document residual risks.

## Report

Create `docs/reports/PHASE_9_REPORT.md`.

Include a risk matrix:
- severity
- finding
- evidence
- mitigation
- status

STOP.
