## Mission

Build the flagship cinematic landing experience.

This is the most important visual phase.

## Requirements

Create a coherent cinematic sequence expressing:

human -> computation -> AI -> robotics -> engineered systems -> Yazan's identity -> portfolio.

Use the supplied portrait.

The portrait must be integrated into the scene professionally rather than pasted as a flat hero image.

## 3D Direction

Use a controlled set of high-quality assets.

Prefer procedural/custom geometry where useful.

Use:
- depth
- lighting
- particles
- computational structures
- mechanical components
- data flows
- restrained volumetric atmosphere

Do not create a random collection of floating 3D objects.

## Scroll

Implement a deterministic scroll timeline with:
- smoothing
- section/progress mapping
- touch support
- keyboard-safe navigation
- reduced-motion fallback

## Performance

Implement at least:
- high quality desktop mode
- reduced quality mode
- mobile fallback
- reduced-motion mode

Measure actual performance.

## Critical Requirement

The scene must have narrative pacing.

Do not optimize away the cinematic identity.

But do not allow visual complexity to make the page unusable.
