# Project Charter

## 1. Product

**Yazan Al Samman — Personal Technology Portfolio**

A premium personal website and private content-management dashboard for an AI-focused information technology engineer.

## 2. Positioning

The site should present Yazan as a technically serious engineer working across AI, software engineering and emerging technology.

The experience should communicate:

- engineering credibility,
- curiosity,
- technical range,
- precision,
- experimentation,
- modern digital craftsmanship.

Avoid generic portfolio clichés such as:
- excessive terminal animations,
- meaningless code rain,
- stock robot imagery,
- neon cyberpunk overload,
- generic "Hello World" hero sections,
- fake metrics,
- invented client logos.

## 3. Primary Audiences

### Recruiters / Employers
Need a rapid understanding of:
- who Yazan is,
- specialization,
- experience,
- strongest projects,
- CV,
- contact channels.

### Technical Peers
Need:
- project architecture,
- technical decisions,
- technologies,
- engineering depth,
- repositories/demos where available.

### Clients / Collaborators
Need:
- capabilities,
- selected work,
- professional presentation,
- contact path.

### General Visitors
Need an intuitive and memorable experience.

## 4. Core Information Architecture

Recommended public routes:

- `/` — cinematic landing
- `/about`
- `/projects`
- `/projects/[slug]`
- `/experience`
- `/skills`
- `/certificates`
- `/cv`
- `/contact`
- `/lab` or `/experiments` — optional
- `/ar/*` or an equivalent locale architecture

The exact routing strategy may be refined after the architecture audit.

## 5. Visual Thesis

The site should feel like a **digital laboratory belonging to an engineer**, not a template.

The cinematic scene should establish a visual metaphor around intelligence and computation without becoming literal or childish.

Possible visual motifs:

- neural structures,
- procedural particles,
- abstract robotic mechanisms,
- computational geometry,
- floating data volumes,
- optical surfaces,
- microchips,
- mechanical joints,
- holographic interfaces,
- volumetric light,
- glass/metal materials,
- an abstract "intelligence core".

Use these as a coherent visual system, not as a random collection of 3D objects.

## 6. Success Criteria

A successful first-time visitor should understand within seconds:

1. This is Yazan Al Samman.
2. He is an AI-oriented technology engineer.
3. He builds real technical projects.
4. The website is intentionally crafted and technically sophisticated.
5. There is substantial professional evidence beyond the hero animation.

The 3D experience must enhance credibility rather than obscure it.
