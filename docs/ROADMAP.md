# Delivery Roadmap

## Phase 0 — Discovery, Audit & Architecture Freeze
Goal:
- inspect repository/environment
- inspect legacy content source
- inspect supplied assets
- choose architecture
- define risks
- freeze initial design direction

Output:
- architecture decision
- content inventory
- implementation plan
- risk register

## Phase 1 — Brand & Design Foundation
Build:
- design tokens
- typography
- global layout
- navigation
- locale foundation
- responsive primitives
- base motion system

## Phase 2 — Content Model & CMS Architecture
Build:
- data model
- admin architecture
- publishing model
- validation
- media model

## Phase 3 — Cinematic Landing Prototype
Build only the flagship experience first.

Deliver:
- storyboard prototype
- 3D scene
- portrait integration
- scroll timeline
- performance tiers
- reduced-motion fallback

This phase must be visually reviewed before the rest of the public site is built around it.

## Phase 4 — Public Site Core
Build:
- about
- projects
- project detail
- experience
- skills
- certificates
- CV
- contact
- footer

## Phase 5 — Dashboard
Build:
- authentication
- overview
- project management
- experience
- certificates
- skills
- CV
- media
- settings

## Phase 6 — Content & Media Pipeline
Build:
- image optimization
- project media
- portrait handling
- PDF/CV handling
- safe uploads
- publishing

## Phase 7 — Bilingual / SEO / Accessibility
Complete:
- Arabic
- RTL
- localized metadata
- structured data
- sitemap
- robots
- accessibility audit

## Phase 8 — Performance & 3D Hardening
Measure:
- bundle size
- load time
- frame rate
- memory
- mobile behavior
- reduced motion

Optimize based on measurements.

## Phase 9 — Security & Production Hardening
Audit:
- auth
- sessions
- uploads
- headers
- dependencies
- secrets
- backups
- production configuration

## Phase 10 — Final QA & Deployment
Verify:
- production build
- tests
- routes
- localization
- SEO
- dashboard publishing
- mobile
- 3D
- accessibility
- deployment
- domain

Each phase must stop after generating its report.
