# SEO & Discoverability

## Primary Domain

`https://yazanalsamman.com`

## Brand Search Targets

The site should clearly establish:
- Yazan Al Samman
- يزن السمان
- Yazan Al Samman Artificial Intelligence Engineer / AI Engineer
- relevant professional/project terms only where factually supported.

The domain spelling `yazanalsamman` is a URL, not a display name. "Yazan Alsamman" may appear only as a documented `alternateName` for search matching (owner approval required), never as the primary identity.

Do not keyword-stuff.

## Required

- unique title per page
- unique meta description
- canonical URLs
- sitemap
- robots.txt
- Open Graph
- Twitter/X cards where useful
- favicon / app icons
- structured data where accurate
- semantic HTML
- descriptive headings
- crawlable project pages

## Structured Data

Potential schema types:
- Person
- WebSite
- CreativeWork / SoftwareSourceCode for appropriate projects
- Article for editorial/project case-study content if applicable

Never create structured-data claims that are not visible or verifiable.

## International SEO

Use correct:
- language attributes,
- canonical strategy,
- hreflang where appropriate,
- localized metadata.

## Performance and SEO

The cinematic landing must not destroy Core Web Vitals.

Prioritize:
- fast initial HTML,
- optimized hero assets,
- progressive 3D loading,
- reserved layout space,
- minimal blocking JavaScript.

## Social Preview

Create a professional default share image using the brand identity and portrait if appropriate.
